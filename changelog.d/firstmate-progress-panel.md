### Added
- A Firstmate progress column on the right (in Brazilian Portuguese) when the server is given a
  Firstmate home in `HERDR_WEB_FIRSTMATE_HOME`: each project's in-flight tasks as a timeline with
  Agora/Histórico, an overview of what needs attention, links to the tasks' open Lavish sessions,
  and a footer that says when the collection is old or missing. A task the snapshot cannot see busy
  shows the state it last logged (Aguardando, Aguardando decisão, Bloqueado, Falhou, Concluído),
  never Em execução. Its left
  edge drags to widen it, like the sidebar's, and it folds to a narrow rail; on a phone it starts
  folded so the terminal stays visible. Without the variable nothing changes.
